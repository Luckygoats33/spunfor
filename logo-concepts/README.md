# Spunfor logo concepts (v4, "spun together")

All marks are original SVG, drawn on a 64 px grid and checked at 16/32 px. Wordmark is **Unbounded Black** converted to outlines (OFL font).
Palette: ink `#0D0D0C`, lime `#C8F31D`, tomato `#FF4A1C`, bone `#F3EFE4`.

| File | Idea |
|---|---|
| `concept-a-spun-pin.svg` | **Primary: Spun Pin.** A map pin whose face is a lime spiral wound outward from a tomato center dot: the pin is literally spun. Reads as pin at 16 px, as a vortex up close. |
| `concept-b-orbit.svg` | **Orbit.** A tomato planet with a spiral core, a lime ring and a moon: trips as things in orbit around you. |
| `concept-c-snap-discs.svg` | **Snap discs.** Four quarter-discs rotating into one circle: modules spinning together into a trip. |

The old "Loop Pin / thread / stitch" concepts were retired; nothing in the system uses stitching, thread or perforation imagery any more.
In the product the mark spins once on load (`.spin-in`) and the pieces of the landing page rotate into place as you scroll. `prefers-reduced-motion` turns this off.

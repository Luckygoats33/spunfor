# Spunfor logo concepts
- **A — Loop Pin (PRIMARY):** a map pin drawn as one thread; the tail loops off like loose yarn. "Spun" thread + "route/place". Reads clearly at 16 px, works as favicon, one gradient + one coral dot.
- **B — Spun Spiral:** a thread spiralling out from a spool-like core and ending in a dot. Pretty, but loses the travel meaning and gets muddy small.
- **C — S Route:** monogram S drawn as a route between two stops. Strong app-icon shape, but more generic (many "S" marks exist).

Primary lives in `../logo.svg`, `../logo-light.svg` (for dark backgrounds), `../logo-mark.svg`, `../favicon.svg`.
Note: wordmark is live text (Inter → system sans fallback). Convert text to outlines in a vector editor before print use.
